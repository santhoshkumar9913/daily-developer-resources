## 💡 Coding Tip of the Day
**Undoing a commit without losing your work:**
If you accidentally committed something too early, you can undo the commit while keeping all your changes perfectly staged by running:
```bash
git reset --soft HEAD~1
```
This is a lifesaver when you just need to add one more file or fix a typo in your commit message!
