## 💡 Coding Tip of the Day
**Use `git commit --amend` to modify your last commit!**
If you forgot to add a file or made a typo in your last commit message, you can easily fix it without creating a messy new commit. Just stage the missing file with `git add <file>` and run:
```bash
git commit --amend --no-edit
```
This is a lifesaver for keeping your Git history clean!
